## 🚀 Inicio Rápido

### Instalación

```bash
# Clonar el repositorio
git clone https://github.com/sae-space-ai/cesacaimg.git
cd cesacaimg

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Abrir en navegador
# http://localhost:5173
```

### Despliegue en Producción

```bash
# Build para producción
npm run build

# Desplegar en Vercel
npm install -g vercel
vercel --prod

# O desplegar en Netlify
npm install -g netlify-cli
netlify deploy --prod
```
