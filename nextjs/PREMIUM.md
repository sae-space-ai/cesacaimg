## 📝 NOTAS TÉCNICAS

### Requisitos del Sistema
- Node.js 18+
- Next.js 14+
- PostgreSQL con pgvector
- Stripe para pagos
- Redis para caché

### Variables de Entorno
```bash
PREMIUM_STRIPE_PRICE_INDIVIDUAL=price_xxx
PREMIUM_STRIPE_PRICE_PRO=price_xxx
PREMIUM_STRIPE_PRICE_BUSINESS=price_xxx
PREMIUM_STRIPE_PRICE_GOVERNANCE=price_xxx
```

### Base de Datos
```sql
-- Tabla de membresías premium
CREATE TABLE premium_memberships (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  tier VARCHAR(20) NOT NULL,
  start_date TIMESTAMP NOT NULL,
  end_date TIMESTAMP NOT NULL,
  auto_renew BOOLEAN DEFAULT true,
  status VARCHAR(20) DEFAULT 'active',
  created_at TIMESTAMP DEFAULT NOW()
);

-- Tabla de acceso a contenido premium
CREATE TABLE premium_content_access (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  content_id UUID REFERENCES premium_content(id),
  accessed_at TIMESTAMP DEFAULT NOW(),
  completed BOOLEAN DEFAULT false
);
```
